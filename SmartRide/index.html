How the File DBMS Works

1. Sequential File (smartride_data.txt):
Stores rider records formatted as "id" "name" "phone" "from" "to" seats.

2. Primary Index (smartride_data.idx):
Stores "RiderID" ByteOffset sorted by key. When searching by ID, binary search finds the key in $O(\log n)$ and seeks directly to the exact byte offset in the text file using seekg().

3. Plain Text Tables:
drivers.txt, roads.txt, and rides.txt use delimiter-separated records for lightweight persistence without requiring any SQL engine.
